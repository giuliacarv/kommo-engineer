# Pacote do guia Kommo Salesbot

1. Descompacte o arquivo `.zip` preservando a estrutura de pastas.
2. Abra `Guia_Salesbot_Kommo.md` em VS Code, Obsidian, Typora, GitHub ou outro visualizador Markdown.
3. Os arquivos de imagem estão em `imagens/`, referenciados de forma relativa no guia. Não mova a pasta sem atualizar os links.

**Aviso:** Os prints originais mostram a interface em 23/10/2026. Blocos sem submenu fotografado usam um recorte do menu principal, rotulado no texto.
