# Auditoria e matriz de homologação
L1: estrutura Agent Skills; L2: utilitários e testes locais;
L3: instalação/ativação/reinício no Codex Windows; L4: efeitos numa conta Kommo autorizada.
Uma camada não aprova a outra. Registre OS, Python, versão da skill, data, escopo, evidência e resultado.
Revisão: conformidade dos registros com os schemas, caminhos, locks, revisão, read-after-write, snapshots, erros,
dados pessoais e uso mínimo de contexto. Nesta versão, os schemas são referências e a CLI não os aplica; não classifique essa checagem como validação por JSON Schema. Não homologue API, Salesbot e n8n apenas por existirem documentos.
