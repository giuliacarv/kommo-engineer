# Contrato: Salesbot visual vs script
Fonte: https://developers.kommo.com/docs/salesbot-dp
Salesbot aceita construtor visual e possui linguagem de scripts com handlers próprios.
Atenção aos blocos `question`, `answer`, `finish` e handlers como `show`, `condition`, `action`,
`goto`, `wait_answer`, `stop`; consulte a documentação *antes de gerar script*.
Diferencie:
1. Visual e opções visíveis na conta.
2. Código do Salesbot/forma de importação.
3. Salesbot SDK de widgets.
4. API REST e n8n JSON.
Não entregar exemplo arbitrário como importável. Verificar gatilhos, canais, transições, fim
e efeito real em contato de teste. Preserve cópia antes de editar fonte do visual.
