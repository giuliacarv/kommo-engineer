# Integração n8n
https://docs.n8n.io/
https://docs.n8n.io/workflows/export-import/
Verifique Cloud vs self-hosted, versão, nodes instalados e permissões.
Prefira HTTP Request quando o node desejado não existir/for incompatível.
Inclua tratamento 429, retries com backoff, correlação, deduplicação e verificação do efeito.
Exportações JSON podem expor headers e informações sensíveis em parâmetros; revise antes de compartilhar.
Não afirme que um workflow foi importado/testado sem execução real.
