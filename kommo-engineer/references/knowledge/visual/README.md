# Biblioteca visual existente

O [catálogo visual](catalog.json) indexa os arquivos de imagem já fornecidos no pacote. Os títulos refletem nomes de arquivo, sem inferir conteúdo, plano, permissão ou comportamento validado. As capturas permanecem em seus caminhos originais e com os mesmos hashes.

O [guia de Salesbot](../../../recursos%20do%20kommo/Guia_Salesbot_Kommo_2026/Guia_Salesbot_Kommo.md) apresenta os menus e as imagens associadas. A origem declara interface de 23/10/2026; recortes de menu principal são diferenciados no guia de submenus fotografados. Use a captura pertinente como referência e observe a conta atual antes de configurar.

Para nova captura ou promoção ao conhecimento reutilizável, registre origem, data, idioma, plano/canal quando conhecidos, tela, opções observadas, pré-requisitos, relações com outros menus, ações documentadas e o que foi efetivamente testado. Não complete metadados ausentes por inferência. Capturas de clientes ficam no projeto; promover somente cópia sanitizada e autorizada. Um arquivo de imagem não comprova configuração atual, execução ou entrega.

O plano anterior previa documentos `UI-KOMMO-NNN.md` e imagens `assets/visual/UI-KOMMO-NNN.png`. Essa convenção continua disponível para novas capturas; as imagens já existentes mantêm sua estrutura para preservar os links e o guia original.
