# Kommo Engineer

Pacote de uma skill do Codex para estratégia, engenharia e operação de Kommo.

- Entrada da skill: kommo-engineer/SKILL.md.
- Os módulos integrados e referências estão em kommo-engineer/references/.
- legado/kommo-mcp/SKILL.md permanece no projeto porque a entrada da skill aponta para esse guia legado.
- A versão e os hashes de integridade do pacote estão em kommo-engineer/manifest.json.

A versão publicada corresponde ao pacote em desenvolvimento 0.4.0-dev. Scripts locais e documentação não comprovam operação em uma conta Kommo real; API, navegador e conta real não foram homologados.
